Frequently Asked Questions

How do I connect to my Kubernetes cluster?

KubeDesk automatically reads your kubeconfig file from ~/.kube/config. Simply ensure your cluster configuration is set up there, and KubeDesk will detect it.

Do I need to install the helper tool?

The helper tool (kubedesk-helper) is optional but recommended for advanced features like cloud provider authentication. You can install it via Homebrew.

How do I manage my subscription?

Subscriptions are managed through the Mac App Store. Go to App Store → Account → Subscriptions to manage or cancel your subscription.
